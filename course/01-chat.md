# 1단계 — 문서 없이 질문하기

## 왜 하나요

작은 모델이 **무엇을 알고 무엇을 모르는지**, 모를 때 어떻게 행동하는지(모른다고 하나, 지어내나)를 먼저 봐요. 이게 RAG 가 필요한 이유예요.

먼저 짐작해서 적어요: "내 문서에만 있는 내용을 물으면 모델은 ___ 할 것이다"

## A. 직접 대화해 보기 (코드 없이)

```sh
ollama run qwen3.5:4b --think=false
```

한 대화창에서 차례대로 쳐 봐요.

| 순서 | 칠 말 | 볼 것 |
|---|---|---|
| 1 | `안녕?` | 한국어가 자연스러운지 |
| 2 | `모르면 모른다고 답해. <내 문서에만 있는 내용 질문>` | 모른다고 하나, 지어내나. 모른다면서 세부를 지어내지 않나 |
| 3 | `한 줄로 답해. <아무 질문>` 다음에 `<다른 질문>` | 앞의 "한 줄로" 지시가 다음 질문까지 이어지나 |
| 4 | `지금 몇 시야?` | 시계가 없는데 시간을 지어내나 |
| 5 | (아무 글도 안 붙이고) `위 글을 요약해줘` | 무엇을 "위 글"로 보나 |

- 3·5번이 이상하게 나오는 이유: 한 대화창에서는 **앞 대화 전체가 다음 질문과 같이 모델에 들어가요**. 그래서 실험할 때는 질문마다 새 대화로 보내야 해요 → 아래 스크립트가 그렇게 해요

## B. 만들 것: `step1_chat.py`

질문 파일 `private/questions.json` 을 먼저 만들어요. 세 종류를 섞어요.

```json
[
  ["일반 지식", "안드로이드 ViewModel 이 화면 회전 뒤에도 데이터를 유지하는 이유를 3줄로 설명해줘."],
  ["내 문서에만 있는 사실", "<내 노트에만 적힌 내용을 묻는 질문>"],
  ["아무도 모르는 것", "우리 동네 도서관의 이번 주 휴관일은 언제야?"]
]
```

- "내 문서에만 있는 사실" 질문은 2·6단계에서 다시 써요. 그 답이 적힌 문서 경로도 같이 메모해 둬요

## AI 에게 줄 말

```text
1단계 스크립트 step1_chat.py 를 만들어줘.
- 목적: 로컬 Ollama 모델에 문서 없이 질문하고 답과 속도를 본다
- 실행: python3 step1_chat.py [모델이름]   (안 주면 qwen3.5:4b)
- 질문: private/questions.json 에서 읽어. 형식은 [["라벨", "질문"], ...]. 파일이 없으면 코드 안의 예시 질문 2개를 써
- 호출: http://127.0.0.1:11434/api/chat 에 POST. stream false, think false, options.temperature 0
- 질문마다 새 대화로 보내 (messages 에 그 질문 하나만)
- 출력: 라벨과 질문, 답, 그리고 "답 N토큰, N초, 초당 N토큰, 모델 로딩 N초"
  (응답의 eval_count, eval_duration, load_duration 을 써. duration 단위는 나노초)
```

## 직접 실행

```sh
python3 step1_chat.py
ollama ps        # 다른 터미널에서. 모델이 GPU 에 올라갔나
```

## 코드에서 꼭 읽을 곳

AI 에게 "이 부분이 왜 이렇게 돼 있는지 한 줄씩 설명해 줘"라고 물어요.

1. 요청 본문의 `"think": False`·`"temperature": 0` — 무엇을 끄고 무엇을 고정했나
2. `eval_duration / 1e9` — 왜 10억으로 나누나
3. `messages` 에 질문 하나만 넣는 부분 — A 의 3·5번 현상과 어떤 관계인가

## 고쳐 보기

| 바꿀 것 | 짐작 먼저 | 확인 |
|---|---|---|
| `temperature` 0 → 0.8, 같은 질문 3번 | 답이 매번 같을까? | 3번 답 비교 |
| `think` False → True | 느려질까? 더 정확할까? | 초당 토큰·답 길이 |
