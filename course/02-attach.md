# 2단계 — 정답 문서를 붙여서 다시 묻기

## 왜 하나요

1단계에서 모델이 지어낸 질문에, **정답이 적힌 문서를 질문과 같이 붙여 주면** 맞히는지 봐요. 찾기(3~5단계)를 만들기 전에 "찾기만 되면 답은 되나"를 먼저 확인하는 단계예요.

먼저 짐작해서 적어요: "정답 문서를 붙이면 6건 중 ___ 건 맞힐 것이다"

## 만들 것: `step2_attach.py`

준비

1. 내 문서 폴더에서 정답이 적힌 문서 1편, 전혀 상관없는 문서 1편을 `private/docs/` 에 복사해요
2. 질문 2개를 정해요
   - 질문 A: 문서에 있는 말을 그대로 쓴 질문
   - 질문 B: 같은 내용을 **일상 말로 바꿔** 물은 질문 (문서에 없는 단어로)
3. `private/step2.json` 을 써요

```json
{
  "system": "한국어로만 답해. 아래 [문서]에 적힌 내용으로만 답하고, 문서에 답이 없으면 '문서에 없어요'라고만 답해. 3문장 이내로 답해.",
  "docs": {
    "정답 문서": "docs/정답.md",
    "엉뚱한 문서": "docs/엉뚱.md"
  },
  "cases": [
    {"label": "A · 문서 없음", "question": "<질문 A>", "doc": null},
    {"label": "A · 정답 문서", "question": "<질문 A>", "doc": "정답 문서"},
    {"label": "A · 엉뚱한 문서", "question": "<질문 A>", "doc": "엉뚱한 문서"},
    {"label": "B · 문서 없음", "question": "<질문 B>", "doc": null},
    {"label": "B · 정답 문서", "question": "<질문 B>", "doc": "정답 문서"},
    {"label": "B · 엉뚱한 문서", "question": "<질문 B>", "doc": "엉뚱한 문서"}
  ]
}
```

## AI 에게 줄 말

```text
2단계 스크립트 step2_attach.py 를 만들어줘.
- 목적: 같은 질문을 '문서 없음 / 정답 문서 / 엉뚱한 문서'로 나눠 묻고 답을 비교한다
- 실행: python3 step2_attach.py [모델이름]   (안 주면 qwen3.5:4b)
- 설정: private/step2.json — {"system": 지시문, "docs": {"문서이름": "private/ 기준 파일 경로"},
  "cases": [{"label", "question", "doc": 문서이름 또는 null}]}.
  파일이 없으면 코드 안의 예시(가상의 도서관 휴관 공지와 질문 2개)를 써
- 사용자 메시지 형식: "[문서]\n[문서 1] 출처: 문서이름\n문서 본문\n\n[질문]\n질문"  (doc 이 null 이면 문서 자리에 "(없음)")
- 호출: /api/chat 에 system 메시지 + user 메시지. think false, temperature 0, num_ctx 8192
- 출력: 라벨, 답, "읽은 입력 N토큰(N초), 답 N토큰(N초)"
  (prompt_eval_count, prompt_eval_duration, eval_count, eval_duration)
```

- `num_ctx` = 모델이 한 번에 읽는 양(토큰). 기본값(1회차 4096)으로는 긴 문서가 잘려요. 최대값은 모델마다 달라요

## 직접 실행

```sh
python3 step2_attach.py
```

## 확인하기 (`내기록.md` 에 적기)

| 항목 | 1회차 | 내 값 |
|---|---|---|
| 6건 중 지어낸 답 | 0 | |
| 질문 A · 정답 문서 | 정답 | |
| 질문 B(바꿔 말함) · 정답 문서 | 사실은 찾았지만 "질문의 말이 문서에 없다"며 판단 보류 | |
| 엉뚱한 문서 | "문서에 없어요" | |
| 입력 읽는 속도 vs 답 쓰는 속도 | 초당 약 500 vs 약 40 토큰 | |

## 코드에서 꼭 읽을 곳

1. `system` 지시문의 "문서에 답이 없으면 '문서에 없어요'라고만" — 이 한 줄이 지어내기를 얼마나 막나
2. 사용자 메시지를 `[문서]`·`[질문]` 으로 나눈 부분 — 모델이 어디까지가 근거인지 알게 하는 방법
3. `prompt_eval_count` — 붙인 문서가 몇 토큰이었나, `num_ctx` 의 몇 %인가

## 고쳐 보기

| 바꿀 것 | 짐작 먼저 | 확인 |
|---|---|---|
| system 에서 "없으면 '문서에 없어요'" 문장 지우기 | 엉뚱한 문서에서 지어낼까? | 엉뚱한 문서 2건의 답 |
| 질문 B 를 문서에 있는 말로 바꾸기 | 판단 보류가 풀릴까? | B · 정답 문서의 답 |
