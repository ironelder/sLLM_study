# 4단계 — 시험지로 찾기 점수 매기기

## 왜 하나요

3단계는 질문 5개로 "잘 찾는 것 같다"를 봤어요. 고친 게 정말 나아졌는지 알려면 **같은 시험지로 매번 점수를 재야** 해요. 이 시험지는 5·6·7·8단계에서도 계속 써요.

| 말 | 쉬운 뜻 |
|---|---|
| recall@1 | 정답 문서가 1위로 나왔나 |
| recall@5 | 정답 문서가 5위 안에 나왔나 (6단계에서 모델에 조각 5개를 붙이니까 이게 중요해요) |

먼저 짐작해서 적어요: "바꿔 말한 질문 10개 중 임베딩이 5위 안에 찾는 건 ___ 개"

## 만들 것 1: 시험지 `private/eval/testset.json`

질문 20개를 내가 써요. 이 단계에서 가장 오래 걸리고, 가장 많이 배우는 부분이에요.

| 묶음 | 개수 | 쓰는 규칙 |
|---|---|---|
| 단어 겹침 (`W01`~`W10`) | 10 | 정답 문서 **제목의 단어를 그대로** 써서 묻기 |
| 바꿔 말함 (`P01`~`P10`) | 10 | 정답 문서의 제목·헤딩·키워드와 **2글자 이상 겹치는 말이 하나도 없게**, 일상 말투로 묻기 |

```json
{
  "exclude_prefix": null,
  "items": [
    {"id": "W01", "group": "단어 겹침", "question": "임베딩 정리 문서에서 정규화는 왜 해?",
     "gold_paths": ["공부/임베딩-정리.md"], "keywords_a": ["임베딩", "정규화"]},
    {"id": "P01", "group": "바꿔 말함", "question": "글을 숫자로 바꾼 다음 길이를 맞추는 이유가 뭐야?",
     "gold_paths": ["공부/임베딩-정리.md"], "keywords_a": ["숫자", "길이"]}
  ]
}
```

- `gold_paths` = 정답 문서 경로. `private/index/chunks.jsonl` 의 `path` 와 똑같은 모양이어야 해요 (정답 문서가 여러 개면 여러 개)
- `keywords_a` = 사람이 검색창에 칠 단어 2~3개. 5단계 키워드 검색에서 써요
- `exclude_prefix` = 결과에서 뺄 경로 (예: 시험지를 적어 둔 메모 폴더). 없으면 `null`
- 바꿔 말함 규칙을 지켰는지 AI 에게 검사시켜도 돼요

```text
private/eval/testset.json 의 P 문항마다, 질문과 정답 문서(gold_paths)의 제목·헤딩·frontmatter keywords 사이에
2글자 이상 겹치는 말이 있으면 표로 알려 줘. 질문은 고치지 마.
```

## 만들 것 2: `step4_eval.py`

```text
4단계 채점 스크립트 step4_eval.py 를 만들어줘.
- 실행: python3 step4_eval.py <시험지.json> <결과.json> [--index private/index] [--top 20]
- step3_search.py 의 load_index 와 embed 를 import 해서 써
- 문항마다: 질문 임베딩 → 모든 조각 점수 → 문서(path)별로 가장 높은 조각 점수를 그 문서 점수로 → 문서 순위 상위 --top 개
- 시험지의 exclude_prefix 가 있으면 그 경로로 시작하는 문서는 빼
- 정답 순위 = gold_paths 중 가장 높은 순위. 상위 --top 안에 없으면 없음
- 출력: 문항마다 "정답 순위, 1위 점수", 끝에 group 별 recall@1 과 recall@5 (예: 바꿔 말함: recall@1=3/10 recall@5=6/10)
- 결과 JSON: {"method": "E", "items": {id: {"top5": [문서 경로 5개], "gold_rank_top": 순위 또는 null, "top1_score": 점수}}}
- 문서 순위를 만드는 부분은 doc_ranking(query, meta, chunks, rows, exclude, top) 함수로 분리해 (5단계에서 import)
```

## 직접 실행

```sh
python3 step4_eval.py private/eval/testset.json results/step4.json
```

## 확인하기 (`내기록.md` 에 적기)

| 묶음 | 1회차 @1 | 1회차 @5 | 내 @1 | 내 @5 |
|---|---|---|---|---|
| 단어 겹침 | 8/10 | 10/10 | | |
| 바꿔 말함 | 3/10 | 6/10 | | |

5위 안에 못 든 문항마다 이유를 골라 적어요 (1회차에서 나온 이유).

| 이유 | 어떻게 알아보나 |
|---|---|
| 흔한 단어에 끌림 | 1위 문서가 질문 속 흔한 단어(회사·서비스 이름 등)가 많이 나오는 문서 |
| 용어 차이 | 문서는 전문 용어, 질문은 일상어 — 뜻은 같은데 못 이음 |
| 비슷한 문서끼리 경쟁 | 정답과 같은 주제 문서가 1~5위를 차지, 정답은 6위 이하 |

## 코드에서 꼭 읽을 곳

1. 조각 점수를 문서별 **최고점**으로 모으는 부분 — 왜 평균이 아니라 최고점인가
2. 정답 순위를 정하는 부분 — 정답 문서가 여러 개일 때
3. group 별로 따로 세는 부분 — 두 묶음을 합쳐서 하나의 점수로 보면 무엇을 놓치나
