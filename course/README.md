# 재수강 교재 — 내 손으로 sLLM·RAG 만들기

1회차(2026-11-11)는 AI 가 설치·실험·코드를 거의 다 했어요. 이 교재는 다른 기기에서 **내가 직접 설치하고, AI 에게 코드를 시키고(바이브 코딩), 결과를 내 눈으로 확인**하면서 같은 8단계를 다시 밟고, 9·10단계에서 분리망·VOC·FAISS 응용까지 해 보는 안내서예요.

## 이 강의에서 배우는 말

| 말 | 쉬운 뜻 | 이 강의에서 |
|---|---|---|
| sLLM | 내 컴퓨터에서 도는 작은 언어 모델 | `qwen3.5:4b` (4GB) |
| Ollama | 모델을 받아서 켜 주는 프로그램 | 내 Mac 안에서만 도는 서버 `127.0.0.1:11434` |
| 토큰 | 모델이 글을 읽고 쓰는 단위 (한글 1~2글자쯤) | 속도를 "초당 토큰"으로 재요 |
| RAG | 답하기 전에 내 문서에서 관련 부분을 찾아 질문과 같이 붙여 주는 방법 | 1·2단계에서 왜 필요한지 보고, 3~6단계에서 만들어요 |
| 조각 (chunk) | 문서를 제목(헤딩) 단위로 자른 작은 덩어리 | 3단계 |
| 임베딩 | 글을 숫자 1024개로 바꿔서, 뜻이 비슷한 글끼리 숫자도 가깝게 만드는 것 | `bge-m3` 모델 |
| recall@5 | 정답 문서가 찾은 결과 5개 안에 들었나 | 4·5단계 점수 |
| BM25 | 단어가 얼마나 겹치나로 찾는 전통적인 키워드 검색 | 5단계에서 직접 만들어 비교 |

## 재수강 방식

```
~/Project/Study/
├── sLLM_study/        ← 이 저장소 = 교재 + 정답지. 여기는 고치지 않아요
└── sLLM_retake/       ← 내가 새로 만드는 폴더 = 내 코드
    ├── private/       ← 내 문서 복사본·질문·시험지·색인 (git 제외)
    └── results/       ← 실행 결과·내 기록 (git 제외)
```

1. 이 저장소를 받아요: `git clone https://github.com/ironelder/sLLM_study.git ~/Project/Study/sLLM_study` (브랜치 `ollama_qwen`)
2. 새 폴더를 만들어요: `mkdir -p ~/Project/Study/sLLM_retake/{private,results} && cd ~/Project/Study/sLLM_retake`
3. git 을 쓰려면 `git init` 뒤 `.gitignore` 에 `private/`·`results/` 두 줄을 먼저 넣어요
4. 그 폴더에서 AI 코딩 도구(Claude Code 등)를 켜고 아래 "세션 시작 때 AI 에게 줄 말"을 붙여 넣어요
5. `00-setup.md` 부터 차례대로 진행해요

## 매 단계 진행 순서

| 순서 | 할 일 |
|---|---|
| 1. 읽기 | 교재의 "왜 하나요"를 읽고, 결과를 먼저 짐작해서 적어요 |
| 2. 시키기 | "AI 에게 줄 말"을 그대로 붙여 넣어요. 내 상황에 맞게 바꿔도 돼요 |
| 3. 읽어 보기 | "코드에서 꼭 읽을 곳"을 AI 에게 쉬운 말로 설명해 달라고 해요 |
| 4. 직접 실행 | 명령은 내가 내 터미널에 쳐요. AI 가 대신 실행하게 두지 않아요 |
| 5. 기록 | "확인하기"의 숫자를 `results/내기록.md` 에 적어요 |
| 6. 고쳐 보기 | 한 군데를 바꾸기 전에 결과를 짐작하고, 실행해서 비교해요 |
| 7. 정답지 비교 | 아래 "정답지와 비교할 때 줄 말"로 1회차 코드와 차이를 확인해요 |

```text
규칙:
- 파이썬 표준 라이브러리만 써 (urllib, json, array 등). pip 설치 없이.

- 코드를 만든 뒤 실행하지 말고, 내가 칠 실행 명령만 알려 줘. 실행은 내가 할게.
- 코드를 만들면 이 코드가 하는 일을 비전공자에게 말하듯 5줄로 설명해 줘.

```

## 지킬 것

- 회사 문서는 회사 기기 밖으로 옮기지 않아요. 다른 기기에서는 내 문서(공부 노트·블로그 글 등)로 해요
- 내 문서·질문·임베딩·결과는 `private/`·`results/` 에만 둬요. 임베딩 숫자에서도 원문 일부를 되살릴 수 있어서 원문과 같게 다뤄요
- Ollama 모델은 로컬 태그만 써요. `cloud` 가 붙은 태그는 질문을 외부 서버로 보내요. `ollama signin` 도 하지 않아요
- AI 코딩 도구에 문서 내용을 읽히면 그 내용은 그 도구의 서버로 가요. Ollama(로컬 모델)는 Mac 밖으로 안 나가요 — 이 차이가 이 강의의 출발점이에요
